thru-ledger-export

Your Thru wallet, as a spreadsheet.

Paste a wallet address and download its whole history as a CSV: every transaction, fee and token movement, with balances that reconcile.

A Thru address starts with “ta” and is 46 characters long. Addresses are public, so no keys or sign-in are needed.

How it works

This page runs entirely in your browser. It reads the address’s public history from Thru’s explorer (scan.thru.org) and token details from Thru’s public RPC node, builds the file on your device, and sends your address nowhere else.

Prefer the command line? npx thru-ledger-export <address> -o ledger.csv does the same. The code is open source on GitHub, where the README explains every column.
